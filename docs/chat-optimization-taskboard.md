## 2. 共同约定

- 沿用 React、TypeScript strict、Ant Design、TanStack Query、Zustand；所有请求继续走业务 API 和 client，Mock 与真实接口链路一致。
- 不引入第二套 UI 组件库；此前提到的 Chatscope 只作为组件和交互参考，不作为默认迁移方案。
- 保留已有修改，只处理当前子任务及必要依赖；提交或推送需用户明确授权。2026-10-19 用户已授权提交并推送 CHAT-004、CHAT-001 到新绑定的前端仓库。
- 命令默认使用 Windows 原生 PowerShell。
- **Codex 负责代码、必要自动测试、排错和验收步骤；用户负责本地网页手动验收。后续不主动操作网站重复验收。**
- 提供给用户验收的服务需保持运行；需要停止时先说明，不在交付后直接关闭。
- 不把连接恢复等同于 REST 数据同步成功；不把前端“未见消息”计数当作后端“未读数”。
- 改变接口、持久化策略或已读业务口径前，说明原因与选项。条件任务不因列入清单而自动启用。
- 后端仓库 `C:/Users/yiwu/Desktop/qg/末期项目/仓库/后端仓库/Qgents` 仅可只读对照；未经用户明确授权不得修改，也不执行会生成文件的构建/安装等操作。

### CHAT-002：SSE 游标过期恢复聊天资源

- 验收：一次 EVENT_CURSOR_EXPIRED 后，不等待下一条新事件即可校准当前消息、群摘要和未读；切项目后的旧恢复过程不污染新项目。
- 边界：与范围外 SSE 计时断言分别记录；若该失败阻碍本卡验证，先说明必要依赖范围。

### CHAT-007B：跨群阅读锚点恢复
